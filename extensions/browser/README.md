# SHANUTECHX Downloader — Browser Extension

Quick 1-click download integration for Google Chrome, Microsoft Edge, Brave, and other Chromium-based browsers.

## How to Install in Chrome / Edge / Brave

1. Open your browser and navigate to:
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
   - Brave: `brave://extensions`
2. Enable **Developer mode** (toggle switch in the top-right corner).
3. Click **Load unpacked**.
4. Select this directory (`extensions/browser`).

## Features

- **Context Menu Integration**: Right-click on any link, image, video, or audio file on the web and click **"Download with SHANUTECHX"**.
- **Popup Quick Downloader**: Click the extension icon in your browser toolbar, paste any link (or use the current tab URL), and click **Download Now**.
- Seamlessly launches the SHANUTECHX desktop application via the custom protocol handler (`shanutechx://download?url=...`).
